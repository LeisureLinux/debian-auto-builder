# debian-auto-builder Repository Setup

## Manual Steps Required:

1. **Create the repository on GitHub first:**
   - Go to https://github.com/new
   - Owner: LeisureLinux  
   - Name: debian-auto-builder
   - Description: Automatic Debian gap scanner and build trigger API
   - Public repository, Initialize with README
   - Click "Create repository"

2. **Then push locally:**
```bash
git remote set-url origin https://github.com/LeisureLinux/debian-auto-builder.git
git push -u origin main
```

3. **Configure required GitHub Secrets:**
After pushing, go to your repo Settings → Secrets and variables → Actions:

| Secret Name | Value | Description |
|------------|-------|-------------|
| `BUILDER_PAT` | Personal Access Token (read:repo + workflow) | To dispatch workflows to deb-builder |
| `GITHUB_TOKEN` | Auto-generated by GitHub | Use in workflows |

4. **Enable Actions:**
   - Go to Settings → Actions → General  
   - Ensure "Allow GitHub Actions" is enabled
